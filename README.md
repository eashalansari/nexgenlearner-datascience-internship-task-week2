## Week 2: Exploratory Data Analysis (EDA) & Visualization

During Week 2, I performed Exploratory Data Analysis on the Loan Prediction dataset to discover patterns, relationships, and meaningful insights from the data.

### Tasks Completed:
- Loaded and explored the cleaned loan dataset
- Checked dataset structure, data types, and statistical summaries
- Analyzed loan approval and rejection patterns
- Studied the relationship between Education and Loan Status
- Analyzed Loan Status based on Property Area and Gender
- Explored the relationship between Applicant Income and Loan Amount
- Created different visualizations using Matplotlib and Seaborn
- Performed correlation analysis using a heatmap
- Extracted key insights from the dataset through EDA

### Visualizations Created:
- Loan Status Distribution Chart
- Education vs Loan Status Chart
- Property Area vs Loan Status Chart
- Gender vs Loan Status Chart
- Applicant Income vs Loan Amount Scatter Plot
- Correlation Heatmap

### Tools & Technologies Used:
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
